## 신입 포트폴리오는 경력자와 다르게 짜야 합니다

경력 스튜디오 견본([08](https://github.com/PORTFOLIOMAKER-SAMPLES/08-millisecond-works))은 "LCP 4.8s → 0.9s" 같은 실무 성과로 채웁니다.
신입은 그 숫자가 없습니다. 그래서 채용 담당자가 실제로 본다고 알려진 것을 대신 담았습니다.

- **결과가 아니라 사고 과정** — 프로젝트마다 *무엇을 하려다 / 어디서 막혔고 / 어떻게 넘겼고 / 다음엔 뭘 다르게 할지*
- **막힌 지점을 숨기지 않기** — 매끄러운 이야기는 오히려 덜 믿깁니다. "useState 일곱 개가 엉켜서 useReducer로 합쳤다" 같은 구체적인 실패가 신뢰를 만듭니다
- **바로 돌아가는 GitHub** — 카드마다 저장소 링크. 클론해서 3분 안에 실행되는지가 기준
- **정직한 현재 위치** — "지금 배우는 것"을 따로 두어 모르는 것을 감추지 않습니다
- **전 직장 경력을 버리지 않기** — 물류회사 3년 → 부트캠프 → 지금까지의 궤적을 날짜와 함께
- **연락 문턱 낮추기** — "코드 리뷰만 주셔도 감사히 받겠습니다"

## 이 견본이 쓴 설정

| | |
|---|---|
| 템플릿 | 3단 분할 (좌 사이드바 · 중앙 · 우 레일) |
| 테마 | 오션 |
| 글꼴 | DM Sans |
| 구성 | 2페이지 (Home · Contact) · 한 페이지(퀵메뉴) |
| 3D | `lamp.glb` (책상 스탠드) + 스튜디오 HDRI 스카이박스 |
| 효과 | 스포트라이트 · 호버 프리뷰 · 스크롤 등장 · 부드러운 스크롤 · 스크롤 진행 바 |
| 파트 | Aside(프로필+목차) · 히어로 · 갤러리 · 태그 · 본문 · 3D · 연혁 · 연락처 · 링크 · 푸터 |
| 용량 | 약 5.1 MB |

**Home** — 왼쪽에 고정되는 프로필 사이드바, 가운데 히어로와 프로젝트 4건, 오른쪽 레일에 "지금 배우는 것" 태그, 아래에 협업 습관과 3D 스탠드.
**Contact** — 날짜가 붙은 성장 연혁, 연락처, GitHub · 개발 일지 · 이력서 링크.

내비게이션은 왼쪽 사이드바 **한 곳에만** 있습니다. 상단 헤더와 목차를 동시에 두면 같은 메뉴가 두 번 보입니다.

## 그대로 가져다 쓰기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `first-commit.pbproj` 선택

프로젝트 카드 네 개의 제목 · 스택 · 요약 · 상세만 본인 것으로 바꾸면 됩니다.
상세 칸에는 **막힌 곳 / 배운 것 / 다음엔** 세 줄 틀이 이미 들어 있습니다.

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 빌드 도구 없는 정적 파일이라 GitHub Pages에 그대로 올라갑니다 — 이 저장소가 그 증거입니다
